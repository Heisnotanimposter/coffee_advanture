## 🌟 1초 만에 무료로 공유하고 사용하는 방법 (Free Sharing Solutions)

누구나 설치나 비용 없이 웹 브라우저나 스마트폰에서 바로 접속하고, 친구나 동료에게 간편하게 공유할 수 있는 **4가지 무료 솔루션**입니다.

### 방법 1. GitHub Pages로 무료 배포하기 (가장 추천! 3번의 클릭으로 영구 무료)
GitHub 저장소에 내장된 무료 호스팅 서비스를 활성화하면 전 세계 어디서나 영구 무료 접속 링크가 생성됩니다.

1. 본 저장소 상단의 **[Settings]** 탭을 클릭합니다.
2. 왼쪽 사이드바 메뉴에서 **[Pages]** 를 선택합니다. (`https://github.com/Heisnotanimposter/coffee_advanture/settings/pages`)
3. **Build and deployment** 항목의 **Source**를 `Deploy from a branch`로 설정합니다.
4. **Branch** 드롭다운에서 `main`, 폴더를 `/ (root)`로 선택한 후 **[Save]** 버튼을 누릅니다.
5. 약 1분 후 배포가 완료되며, 아래 주소로 누구나 무료로 접속할 수 있습니다:
   ```text
   https://heisnotanimposter.github.io/coffee_advanture/
   ```
*(루트에 리디렉션용 `index.html`이 자동 설정되어 있어 서브 폴더 경로를 칠 필요 없이 위 주소로 바로 열립니다)*

---

### 방법 2. 설정 없이 지금 당장 열람하기 (Zero-Config Instant CDN)
GitHub Pages 설정을 기다릴 필요 없이 즉시 HTML/CSS/JS 렌더링 결과를 보고 싶을 때 사용합니다.
- **즉시 실행 링크**: [raw.githack 미리보기 열기](https://raw.githack.com/Heisnotanimposter/coffee_advanture/main/coffee_and_camping_HIN/index.html)
- 링크를 복사하여 카카오톡, 슬랙, 메시지 등에 붙여넣기만 하면 상대방이 즉시 브라우저로 체험할 수 있습니다.

---

### 방법 3. 원클릭 무료 클라우드 배포 (Vercel & Netlify)
자신만의 커스텀 도메인이나 독립 호스팅이 필요할 경우, 아래 버튼을 한 번 클릭하면 무료 계정으로 10초 만에 글로벌 CDN 배포가 완료됩니다.

| 제공사 | 원클릭 배포 버튼 | 특징 |
| :--- | :--- | :--- |
| **Vercel** | [![Deploy with Vercel](https://vercel.com/button)](https://vercel.com/new/clone?repository-url=https://github.com/Heisnotanimposter/coffee_advanture) | 초고속 Edge CDN, Git Push 시 자동 무중단 재배포 |
| **Netlify** | [![Deploy to Netlify](https://www.netlify.com/img/deploy/button.svg)](https://app.netlify.com/start/deploy?repository_url=https://github.com/Heisnotanimposter/coffee_advanture) | 1-Click 무료 호스팅 및 무제한 SSL 인증서 |

*(프로젝트 내 `vercel.json` 및 `netlify.toml`이 사전 구성되어 있어 별도 빌드 설정 없이 바로 동작합니다)*

### 방법 4. 웹 앱 내부 "원클릭 공유(SHARE)" 기능
본 서비스 우측 상단 네비게이션 헤더에 **[SHARE]** 버튼이 탑재되어 있습니다.
- **모바일 브라우저 (스마트폰)**: 카카오톡, 인스타그램, 문자메시지, 에어드롭(AirDrop) 등 기기 기본 공유창이 즉시 실행됩니다.
- **PC 데스크톱 브라우저**: 클릭 한 번으로 서비스 접속 링크가 클립보드에 자동 복사되며 토스트 알림이 뜹니다.

## ✨ 핵심 기능 소개 (Key Features)

1. **에디토리얼 매거진 룩북 & 인터랙티브 핫스팟 (Content-to-Commerce)**
   - 1,256m 평창 청옥산 육백마지기 아침 운해 화보 & 제주 금릉 바다 캠핑 화보
   - 화보 속 장비 및 커피 원두에 펄스(Pulse) 애니메이션 핫스팟 탑재 → 클릭 시 상세 스펙 및 팁 확인
2. **Web Audio API 기반 자연 앰비언스 사운드 (Nature Ambience Player)**
   - 우측 상단 `Sound: Nature` 버튼 클릭 시 장작 소리, 바람, 새소리가 재생되어 아웃도어 감성을 극대화
3. **로케이션별 바리스타 브루잉 레시피 (Brewing Guide)**
   - 고지대 기압차를 고려한 물 온도 제어(93.5℃), 침출 시간, 푸어오버 가이드 상세 제공
4. **장바구니 드로어 & 모의 결제 시스템 (Cart & Checkout Simulator)**
   - 에디터 추천 기어/원두를 즉시 장바구니에 담고 수량 조절 및 결제 프로세스 체험
5. **100% 모바일 반응형 UX (Mobile First Responsive Design)**
   - 스마트폰, 태블릿, 데스크톱 전 화면 해상도 완벽 대응

## 💻 로컬에서 실행하기 (Local Development)

별도의 라이브러리 설치(npm install 등) 없이 순수 웹 표준(Vanilla HTML/CSS/JS)으로 제작되어 즉시 실행할 수 있습니다.

### Python 사용 시 (터미널)
```bash
# 저장소 루트에서 다음 명령어 실행
python3 -m http.server 8080

# 브라우저에서 http://localhost:8080 접속
```

### VS Code 사용 시
1. VS Code에서 본 폴더를 엽니다.
2. `coffee_and_camping_HIN/index.html` 파일을 우클릭하고 **[Open with Live Server]** 를 선택합니다.
